# Política de Privacidade: Agenda Pessoal

Última atualização: 27 de outubro de 2026

## O que é este aplicativo

A Agenda Pessoal é um aplicativo de uso pessoal e não comercial, mantido por um indivíduo
para organizar os próprios compromissos. Não é um produto oferecido ao público, não tem
usuários além do próprio autor e não é vendido nem licenciado.

## Quais dados são tratados

O aplicativo trata apenas os dados que o próprio autor insere nele:

- Título, data, hora e categoria dos compromissos que ele cria.
- O texto das mensagens que ele mesmo envia ao aplicativo pelo WhatsApp, usado só para
  interpretar o comando (por exemplo, "amanhã 14h dentista") e responder a confirmação.
- O número de telefone do autor, usado apenas para verificar que a mensagem veio dele e
  para devolver a resposta.

Mensagens de qualquer outro número são descartadas sem processamento.

## Onde os dados ficam

Todos os dados ficam em um arquivo de banco de dados no computador pessoal do autor. Não há
servidor na nuvem, não há banco de dados hospedado por terceiros e não há cópia em nuvem.

## Compartilhamento

Nenhum dado é compartilhado, vendido, cedido ou enviado a terceiros. O aplicativo não usa
serviços de publicidade, de análise de uso nem de rastreamento.

A única transmissão externa é a troca de mensagens com a API do WhatsApp da Meta, necessária
para que o aplicativo receba o comando e envie a resposta ao próprio autor.

## Retenção e exclusão

Os dados ficam armazenados enquanto o autor quiser e são excluídos por ele a qualquer momento,
apagando o arquivo do banco de dados no próprio computador. Não existe cópia em outro lugar
que precise ser solicitada a terceiros.

## Segurança

O acesso ao aplicativo pela internet exige um token secreto. As mensagens recebidas do WhatsApp
são validadas por assinatura criptográfica (HMAC-SHA256) antes de serem processadas, e qualquer
mensagem sem assinatura válida é recusada.
